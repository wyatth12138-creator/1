# 效用目标与采集配置

当前效用采集支持三种目标，配置在`utility`中。它们共用当前候选、可删除项、真实监督可用位置与续接协议，不要求分类/分割病例配对。

```json
{
  "utility": {
    "target_objective": "task",
    "reuse_prefix": true,
    "behavior_policy": "fifo",
    "continuation_policy": "fifo",
    "tie_continuation_to_behavior": true
  }
}
```

`task`是原来的真实任务损失：分割仅在有效mask位置，分类只在检查终帧。`pointer_consistency`对比有界删除分支与同一冻结reader全历史教师的输出pointer余弦距离。`output_consistency`使用教师分割软BCE或分类概率KL。后两者是reader内部代理对照，不是SPACE/JEPA复现；教师预测不等于真实标注。它们仍匹配原任务的监督有效性，因此不构成整项研究的无标注训练方案。

代理教师沿同一输入按时间因果读取，一次性保存各时刻的全历史输出；不读取标签值，离线使用全部过去bank。其计算和缓存增长需要计入采集成本，不能当作有界部署模型。

`reuse_prefix=true`对确定性续接复用重叠未来前缀，保留原聚合公式；random续接继续用每窗口原随机流。直接调用`collect_examples`时默认关闭，engine默认开启，可用同配置只切此开关作精度/计算对照。

`tie_continuation_to_behavior=true`保留此前规则：FIFO行为读取显式continuation，其他行为令continuation等于behavior。设为false时，两个策略始终独立取配置。实际生效策略、目标、教师定义、复用开关和源码哈希都进入缓存指纹；改变协议需用新输出目录。

`utility_index.json`新增`utility_statistics`，分别记录两个轴的观测状态数、精确零代价状态数与最大绝对代价。零标签不自动表示模型或输入无价值：无对象桥的原生分类token只取当前图像，在FIFO续接把所有差异token洗出后，两个分支的终帧分类输出会相同。统计这一现象时需按horizon/容量和reader配置分层，不能给全零标签随意加噪声。

各目标使用同一冻结reader与相同监督可用性；策略比较继续检查reader哈希相同。新来源适配、对象桥与多任务梯度改进应独立比较，不将总收益都归给目标替换。

## 评估报告的统计身份

policy_reports.json显式保存evaluation_split、拟合运行fit_seed、policy随机数policy_seed、视频采样与实际加载的reader/目标协议。每实体records.seed表示拟合运行，policy_seed单列；读者开发选模也使用正确的拟合种子。训练重复和随机淘汰抽样不能互相冒充。模型评估前截取reader配置，避免末个policy/容量覆盖其身份。

同一主要结果的各种子必须有一致的输入采样和目标定义。例如CAMUS仅LV目标[5]与三目标平均Dice不是同一终点。后处理应验证这些字段；旧报告未提供充分元数据时，不能仅靠同名病例认定协议相同。
