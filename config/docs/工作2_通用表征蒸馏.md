# 工作2：把互补教师能力蒸馏进同一个超声读者

目标是让部署时仍只有TUM-US一个模型，同时学习更好的整图语义和目标空间表征。工作1先改善各任务怎样共同训练；工作2再改变训练时能获得哪些额外表征监督，两项贡献分别比较。

## 推荐模型安排

学生保留TUM-US SAM2 Small、已有任务头和时序记忆。第一阶段仅使用一个冻结RADIO教师，读出其全局与局部特征，训练两个很小的学生投影头；不把教师装入推理路径。随后加入实际训练合格的超声分类、分割专科教师，检验通用教师与领域教师是否互补。目前并没有这些教师在本地数据上已合格的证据，不能把现有随机/弱任务头当作强教师。

C-RADIOv4的SO400M/H约4.12亿/6.31亿参数，适合作冻结教师候选。12GiB条件下优先离线缓存训练图像特征，或降低教师分辨率/每视频抽帧；学生仍按自己的完整视频采样训练。先实测资源，再确定教师规格。不下载所有教师堆进当前学生，也不声称复现尚未公开的完整RADIOv4训练流程。

## 蒸馏如何对应独立数据

- 同一张输入图像：教师全局token对应学生全局token；教师空间网格与学生FPN按坐标插值后对应。视频只对真实采样帧做这项监督，绝不跨患者找分类—分割对应。
- 不同标注来源：分类损失只读该来源分类真值，分割损失只读该来源真实掩码；无标注任务不增加伪真值。教师特征蒸馏可在这些输入上共同进行，但不因此把诊断标签或解剖定义合并。
- CEUS双视图：B模和造影视图分别蒸馏，同步对应仅限已有可靠同步证据的视图；普通彩色视频教师的特征不能直接代表造影灌注动力学。
- 时序能力：单帧RADIO教师不能直接教授长期记忆和造影阶段判断。这部分继续使用真实视频任务监督，必要时另引入合格视频教师。

## PHI-S的正确借鉴

先检查每个教师特征的均值、协方差和总方差，再拟合训练集内固定归一化。PHI-S使用旋转和单一标量缩放来平衡维度方差；它不是把所有特征特征值都改为1的完全白化。

可写成`z = alpha * H * U^T * (x - mu)`，其中协方差分解`C=U Lambda U^T`，`H`为归一化Hadamard矩阵，`alpha=1/sqrt(mean(diag(Lambda)))`。需处理不满足Hadamard维数的实际特征，不能不加说明照搬方阵。统计量只从训练输入估计，各来源均衡抽样；dev/test不参与拟合。全局与局部特征分别统计。它主要改善蒸馏目标的尺度分配，不能据此断言任务冲突都由尺度导致。

推荐损失：真实任务监督＋全局特征蒸馏＋空间特征蒸馏，系数在开发集选择。工作1的共享梯度优化只在另外一组开启，以辨别蒸馏与优化是否各自有用。教师概率输出仅在标签空间真实一致时做logit蒸馏。

## 实验顺序

1. 固定工作1选定学生、数据与采样，记录无蒸馏结果和部署成本。
2. 同一冻结教师比较：不归一化、简单均值/标量标准化、PHI-S；相同投影容量与蒸馏预算。
3. 分别比较全局、局部、两者共同蒸馏，再比较通用教师、合格超声专科教师与组合。
4. 最后交叉“蒸馏开关×工作1训练机制开关”，评估各来源、跨来源接入和旧能力。报告教师训练/缓存成本、学生参数、吞吐、显存、视频时序表现；不能仅报均值。

这可能形成工作2的研究问题：**通用视觉教师的语义/空间知识，经来源均衡的统计校准后，能否同时改善独立超声分类与分割，并转移到新来源？** 采用现成RADIO或PHI-S本身不是新颖性。论文贡献需要来自超声中可复验的条件、机制或有效新方法。
